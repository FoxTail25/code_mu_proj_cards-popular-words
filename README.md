# 🇬🇧 Проект «Карточки 1000 английских слов»

Интерактивное веб-приложение для эффективного заучивания самых популярных слов английского языка. Проект разработан на чистом JavaScript (Vanilla JS) в рамках обучения по программе Дмитрия Трепачёва (Уровень 2) и доведен до уровня Production-ready продукта.

---

## 🚀 Ключевые особенности и функционал

*   **Интерактивное заучивание:** Система поочередно выводит карточки со словами. Пользователь может подтвердить знание слова («Знаю») или посмотреть перевод при затруднении («Не знаю»).
*   **Умная система повторения (Память):** Приложение автоматически сохраняет прогресс в `LocalStorage`. Выученные слова исключаются из основного пула, но периодически «примешиваются» обратно для проверки долгосрочной памяти. Если пользователь забыл слово, оно возвращается в список изучения.
*   **Интерактивная статистика:** Встроенная таблица результатов с динамической фильтрацией («Все слова», «Изученные», «Осталось выучить») для наглядного отслеживания прогресса.
*   **Сброс прогресса:** Кнопка полной очистки истории заучивания и обновления базы данных.

---

## 🛠️ Технический стек и архитектура

*   **Язык:** JavaScript (ES6+), HTML5, CSS3.
*   **Архитектура:** Модульная структура (ES-модули) с разделением зон ответственности (работа с хранилищем, генерация случайных чисел, рендеринг компонентов интерфейса, управление состоянием игры).
*   **ООП-подход:** Логика работы с браузерным хранилищем вынесена в изолированный класс-обертку с безопасным парсингом данных.
*   **Производительность:** UI-компоненты генерируются «на лету» через паттерн клонирования скрытых DOM-шаблонов (`cloneNode`), что исключает громоздкий HTML-код внутри скриптов.
