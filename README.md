## 🚀 Ключевые особенности и функционал

*   **Интерактивное заучивание:** Система поочередно выводит карточки со словами. Пользователь может подтвердить знание слова («Знаю») или посмотреть перевод при затруднении («Не знаю»).
*   **Умная система повторения (Память):** Прогресс автоматически сохраняется в `LocalStorage`. Выученные слова исключаются из основного пула, но периодически «примешиваются» обратно для проверки долгосрочной памяти. Если слово забыто, оно возвращается в список изучения.
*   **Интерактивная статистика:** Встроенная таблица результатов с динамической фильтрацией («Все слова», «Изученные», «Осталось выучить») для наглядного отслеживания прогресса.
*   **Сброс прогресса:** Кнопка полной очистки истории заучивания и обновления базы данных.

## 🛠️ Технический стек и архитектура

*   **Язык:** JavaScript (ES6+), HTML5, CSS3.
*   **Архитектура:** Модульная структура (ES-модули) с четким разделением зон ответственности (работа с хранилищем, генератор случайных чисел, рендеринг компонентов интерфейса, управление состоянием игры).
*   **ООП-подход:** Логика работы с браузерным хранилищем вынесена в изолированный класс-обертку с безопасным парсингом данных и защитой от поврежденных JSON-строк (`try/catch`).
*   **Оптимизация DOM:** UI-компоненты генерируются «на лету» через паттерн клонирования скрытых DOM-шаблонов (`cloneNode`), что исключает громоздкий HTML-код внутри скриптов. Для предотвращения утечек памяти применены одноразовые слушатели событий (`{ once: true }`).
